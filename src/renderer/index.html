    Chrome / Edge / Brave / Opera:

    3. Select "Export passwords"
    4. Save the CSV file
    Note: CSV format should have columns: name, url, username, password

    Toolbar

    Tab Management & Startup

    On startup

    Restore open tabs from the previous session. Turn this off to start on your home page. Pinned tabs, favorites and spaces always stay.

    Today tabs

    Archived tabs are one click away in the Archive (Ctrl+Shift+A). Pinned tabs and favorites are never archived.

    Memory

    A sleeping tab frees its memory and reloads when you open it. Tabs playing sound and private tabs never sleep.

    Links

    Peek opens a page over the one you are on. Keep it as a tab, put it in split view, or press Esc.

    Moving from Arc

    Bring over Arc's spaces, pinned tabs, folders and favorites. Arc's files are only read, never changed.

    Browsing

    New tabs use the home page chosen in General. Use the History panel to revisit pages and Tab Expose to see all open tabs.

    Search

    Default search engine
    Suggestions

    Brave suggestions use its official Autosuggest API when a key with Autosuggest access is configured. Scira and DuckDuckGo Quick use local history suggestions. Private tabs never request online suggestions.

    Brave Search API

    Get full web results inside Shiira. Add your own API key from the Brave API dashboard. Provider usage limits and charges apply.

    No API key configured.

    Scira AI API

    Get AI answers with sources, plus Reddit, X and people searches. Create a key on the Scira API platform. Provider usage limits and charges apply.

    No API key configured.

    Keys are saved in your operating system’s keychain. DuckDuckGo Quick needs no key and offers instant answers and related topics.

    Extensions

    Chrome Web Store

    Shiira runs Chrome extensions (Manifest V3) from the Chrome Web Store. Open the store, choose an extension and press Add to Chrome. Shiira shows what it will be able to do before it is added. Extensions update on their own.

    Installed

    Extensions run in normal tabs and never in private tabs. Their buttons appear next to the address bar. A few Chrome-only features may not work yet.
